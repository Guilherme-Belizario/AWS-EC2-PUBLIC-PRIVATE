# AWS-EC2-PUBLIC-PRIVATE
Implementação de instâncias EC2 em subnets públicas e privadas utilizando AWS

AWS EC2 – Subnets Pública e Privada

## Objetivo
Criar e configurar duas instâncias EC2 em uma mesma VPC, sendo uma em subnet pública e outra em subnet privada, validando a conectividade entre elas e com a Internet.

## Serviços e tecnologias
- Amazon EC2
- Amazon VPC
- Subnets públicas e privadas
- Security Groups
- SSH
- ICMP

## Arquitetura
- VPC: 10.0.0.0/16
- Subnet pública: 10.0.1.0/24
- Subnet privada: 10.0.3.0/24
- Região: US East (N. Virginia)

## Atividades realizadas
- Criação das instâncias EC2.
- Configuração de uma instância pública e outra privada.
- Configuração de regras de segurança.
- Acesso via SSH.
- Testes de conectividade com ping.

## Aprendizados
Prática de criação e configuração de instâncias EC2, segmentação de rede com subnets públicas e privadas e validação de conectividade dentro de uma VPC.
